# Планирование дистанций в Mapper: руководство

Это описание кастомного функционала, добавленного поверх апстрима OpenOrienteering
Mapper: модуль планирования дистанций (курсов) и экспорт координат карты для
интеграции с проектом **Competra**. Апстримный механизм "Simple course" (один
нарисованный путь → IOF/KML) не описывается здесь подробно — он не связан с новым
модулем и упомянут только для разграничения.

## Модель данных

Всё в `src/course/`:

- **`CourseControl`** — один контрольный пункт: `id` (уникальная строка, например
  "S1", "F1", "101"), позиция на карте, сдвиг подписи номера, тип
  (`Start` / `Regular` / `Finish` / `CrossingPoint`), карточка описания IOF
  (`ControlDescription`: code, feature part, feature, approach, dimensions,
  location detail, other info — колонки B–H карточки ISCD).
- **`Course`** — именованная дистанция: имя, тип (`Linear` или `Score`), список
  записей `CourseEntry` (`control_id` + `points`), набор высоты `climb_m`
  (вводится вручную), масштаб легенды, очки по умолчанию для Score-дистанций.
- **`CourseDatabase`** — контейнер верхнего уровня, хранится как часть `Map`
  (`map->courseDatabase()`). Содержит общий пул контролей (переиспользуются
  разными дистанциями) и список дистанций, а также позицию легенды на карте.
  Сигналы (`controlAdded/Changed/Removed`, `courseAdded/Changed/Removed`)
  обновляют панель и отрисовку на карте без опроса.

Связь: одна `CourseDatabase` на карту → общий пул `CourseControl` → несколько
`Course`, каждая ссылается на подмножество контролей по `id` в заданном порядке
(или без порядка для Score-O).

Дистанции и контроли сохраняются прямо в файле карты (`.omap`), в элементе
`<courses>`. Старые версии Mapper при чтении такого файла просто пропускают этот
элемент — обратная совместимость сохраняется.

## Как создать дистанцию

1. **`Map → Courses → Place Control`** — активирует инструмент расстановки
   контролей. Клик по пустому месту карты создаёт новый КП; тип нового КП
   (Start / Regular / Finish / Crossing) задаётся кнопками на вкладке *Controls*
   панели. Клик по существующему КП выделяет его, перетаскивание — перемещает,
   `Delete` — удаляет выделенный, `Escape` — выключает инструмент. Все действия
   идут через undo-стек.
2. **`Map → Courses → Course Planning`** — открывает/закрывает докуемую панель
   `CoursePanelWidget` с двумя вкладками: *Controls* и *Courses*.
3. На вкладке **Courses** — кнопка добавления новой дистанции, задать имя.
4. На вкладке **Controls** — выделить нужные КП (см. раздел про
   множественное добавление ниже), выбрать целевую дистанцию в выпадающем
   списке "Add to course:" и нажать **Add**.
5. На вкладке **Courses** для выбранной дистанции задать: тип (Linear/Score),
   Climb (набор высоты, вручную), Legend scale (масштаб легенды — можно также
   регулировать перетаскиванием прямо на карте).
6. Легенда (ISCD-таблица описания КП) — перетаскиваемый объект на карте, её
   позиция запоминается в файле карты.

## Типы дистанций: Linear и Score-O

- **Linear** — контроли проходятся в заданном порядке; между ними рисуются
  соединительные линии, подпись на карте — порядковый номер.
- **Score** (Score-O) — контроли можно проходить в любом порядке, за каждый
  начисляются очки:
  - `default_points` дистанции (по умолчанию 2) — очки, присваиваемые новым
    и не переопределённым вручную записям.
  - Индивидуальные очки записи — поле-спинбокс "Points:" под списком записей
    выбранной дистанции.
  - При переключении Linear → Score все записи с очками `0` автоматически
    получают `default_points`.
  - При изменении `default_points` синхронно сдвигаются очки у всех записей,
    которые не были переопределены вручную.
  - Для Score-дистанций: соединительные линии между КП не рисуются, подпись на
    карте — код контроля (не порядковый номер), в легенде колонка номера
    показывает очки.

## Множественное добавление контролей

На вкладке **Controls**:

- Дерево контролей поддерживает выбор **без Ctrl** — обычный клик добавляет
  или убирает строку из выделения (toggle), `Shift`+клик выделяет диапазон как
  обычно.
- Порядок выбора запоминается в порядке кликов (не в порядке списка) — важно,
  если порядок КП имеет значение при последующем добавлении.
- Под деревом — счётчик выделения ("Selected (N): код1, код2, …") и панель
  "Add to course:" с выбором целевой дистанции и кнопкой **Add** — добавляет
  сразу все выделенные КП в дистанцию одним действием, без переключения на
  вкладку Courses. Для Score-дистанций добавленным записям сразу присваиваются
  очки по умолчанию.

**Как пользоваться:** кликами (без Ctrl) выбрать несколько КП в нужном
порядке на вкладке Controls, `Shift` — для выбора диапазона; в списке
"Add to course:" выбрать дистанцию; нажать **Add**.

## Легенда ISCD

- Легенда — табличная карточка описания контролей со стандартными пиктограммами
  ISCD (~25 векторных символов: boulder, depression, building, marsh, wall,
  path и т.д.), рисуется поверх карты для колонок C/D/E/G описания КП, с
  текстовым fallback для нераспознанных значений.
- Легенда перетаскивается прямо на карте; её позиция и масштаб сохраняются в
  файле карты.
- Для Score-дистанций первая колонка легенды показывает очки вместо
  порядкового номера.
- Кастомную геометрию отдельных символов ISCD можно перерисовать через
  **`Map → Courses → ISCD Symbol Reference… → Symbol Editor...`** — графический
  редактор (линии, дуги, овалы, круги, квадраты, точки), хранит изменения в
  `iscd_symbols.json` и переопределяет встроенную отрисовку при совпадении кода
  символа.

## Экспорт дистанций

Два независимых механизма — важно не путать:

| Пункт меню | Формат | Что экспортирует |
|---|---|---|
| `File → Export → Simple course` | IOF XML или KML | Апстримный механизм: один нарисованный путь (`PathObject`) как простая дистанция. Не связан с модулем `CourseDatabase`. |
| **`Map → Courses → Export IOF (full course database)…`** | IOF XML | **Наш модуль**: все дистанции карты, общий пул контролей, карточки описания IOF, тип дистанции (Linear/Score), длина и набор высоты. |

Для выгрузки дистанций, спланированных через панель Course Planning, всегда
используйте **`Map → Courses → Export IOF (full course database)…`** — диалог
сохранения файла, результат `*.xml`.

---

## Импорт дистанций

Кнопка **Import** в верхней части панели Course Planning открывает `.courses`
файл (тот же XML-формат с тегом `<courses>`). Файл сначала загружается во
временную базу — если он повреждён, текущая карта не пострадает — а затем
заменяет/сливает с текущей `CourseDatabase` (операция поддерживает undo).

## Длина и набор высоты в IOF XML

При экспорте через "Export IOF (full course database)" в каждый `<Course>`
добавляются:

- **`<Length>`** — вычисляется автоматически: сумма расстояний между
  последовательными КП дистанции переводится из миллиметров карты в метры через
  масштаб карты (округляется). Пишется, только если длина больше 0.
- **`<Climb>`** — значение поля "Climb", введённое вручную на панели.
  Пишется, только если больше 0.

Формат соответствует тому, что уже разбирает `IOFXmlParser.kt` в проекте
**eSport** (backend) — это часть кросс-проектной интеграции Mapper → eSport,
аналогично функции Competra ниже. При дальнейших изменениях формата IOF-экспорта
стоит сверяться с этим парсером.

## Copy WGS84 map corners for Competra

Функция для передачи географических границ экспортированного изображения карты
на сайт **Competra**, чтобы привязать загруженную карту дистанции к реальным
координатам.

**Расположение в GUI:** диалог экспорта карты, доступный через
`File → Export...`, чекбокс **"Copy WGS84 map corners for Competra"**
(рядом с "Сохранить world файл" / "Show grid" / "Simulate overprinting" /
"Transparent background").

### Пошаговая инструкция

1. Убедитесь, что карта геопривязана: **`Map → Georeferencing`**. Если карта
   не геопривязана, чекбокс будет неактивен, с подсказкой "The map must be
   georeferenced (Map > Georeferencing) for this."
2. **`File → Export...`**, в качестве цели экспорта выберите **Image**
   (растровое изображение, PNG/TIFF/JPEG и т.п.) — чекбокс появляется только
   для этой цели.
3. Отметьте галочку **"Copy WGS84 map corners for Competra"** (при
   геопривязанной карте она включена по умолчанию).
4. Выполните экспорт — укажите путь для файла изображения и нажмите
   "Экспорт...".
5. После успешного сохранения изображения появится диалог **"Competra map
   bounds"** с 4 строками координат — они уже скопированы в буфер обмена:
   ```
   mapTopLeftLat=...
   mapTopLeftLng=...
   mapBottomRightLat=...
   mapBottomRightLng=...
   ```
   Координаты — с точностью 7 знаков после запятой.
6. Вставьте (`Ctrl+V`) содержимое буфера в форму загрузки карты дистанции на
   сайте Competra.

**Технические детали (для разработчика):** координаты получаются переводом
области печати (`MapPrinter::getPrintArea()`) в WGS84 через
`Georeferencing::toGeographicCoords()`. Карта считается "north-up" (стандартная
ориентация печатных карт ориентирования) — поэтому вместо честной аффинной
трансформации 4 углов берётся географический bounding box (min/max широты и
долготы) этих точек. Ничего не пишется в файл — только буфер обмена и
информационное окно.

## Undo/redo

`src/course/course_undo.h` — 7 подклассов `UndoStep`:

- `AddControlUndoStep`, `RemoveControlUndoStep`, `MoveControlUndoStep`,
  `MoveControlNumberUndoStep`, `ModifyControlDescriptionUndoStep` — точечные
  операции с одним контролем.
- `CoursesChangedUndoStep` — снапшот всего списка дистанций, используется
  большинством операций в панели (переименование, добавление/удаление записи,
  смена типа, очков и т.д.).
- `ReplaceCourseDatabaseUndoStep` — снапшот всей базы целиком, используется при
  импорте `.courses`-файла.
